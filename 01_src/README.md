# Zona de TV - App Android nativa para listas M3U / IPTV
#
# Identificador de la aplicación (applicationId): erasom.zonadetv
#
# Cómo abrir este proyecto:
# 1. Abre Android Studio.
# 2. Selecciona "Open" y busca la carpeta:
#    D:\Antigravity\erasomlabs\zonadetv\01_src
# 3. Espera a que Gradle sincronice y descargue las dependencias.
# 4. Conecta un dispositivo Android o inicia un emulador.
# 5. Haz clic en Run (▶) para compilar e instalar.
#
# Funcionalidades incluidas:
# - Pegar URL de lista M3U (ej. de iptv-org en GitHub)
# - Cargar archivo M3U local desde el dispositivo
# - Selector de canales (sin logos, carga rápida)
# - Reproductor integrado con ExoPlayer
# - Guarda la última URL usada
#
# Notas importantes:
# - Este proyecto aún no tiene ID de AdMob. Cuando lo tengas,
#   agrégalo en AndroidManifest.xml dentro de <application>:
#     <meta-data
#         android:name="com.google.android.gms.ads.APPLICATION_ID"
#         android:value="ca-app-pub-xxxxxxxxxxxxxxxx~yyyyyyyyyy" />
# - Para firmar la APK y subirla a Google Play Console, usa la
#   misma clave de subida (upload key) si ya publicaste una versión previa.
